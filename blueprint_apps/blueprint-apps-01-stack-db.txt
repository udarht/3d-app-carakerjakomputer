==================================================
2. DATABASE ARCHITECTURE & RELATIONS
==================================================
[Tabel: hardware_items]
- Pengelola Kode : src/lib/hardwareData.ts (Interface: HardwareItem & HARDWARE_LIST) & src/lib/data/hardware.js (hardwareData)
- Kolom Kunci    :
  * id (PK)
  * category (FK -> hardware_categories.id)
- Kolom Penting  : [name, icon, shortDesc, description, specs, workingPrinciple]
- Relasi         :
  * hardware_items --(many-to-one)--> hardware_categories via category
  * hardware_items --(1-to-1)--> quiz_items via id

[Tabel: hardware_categories]
- Pengelola Kode : src/lib/data/quiz.js (categoryDefinitions) & src/lib/hardwareData.ts
- Kolom Kunci    :
  * id (PK)
- Kolom Penting  : [title, subtitle, desc, icon, color]
- Relasi         :
  * hardware_categories --(1-to-many)--> hardware_items via category
  * hardware_categories --(1-to-many)--> quiz_items via correctCategory

[Tabel: quiz_items]
- Pengelola Kode : src/lib/data/quiz.js (quizItems & QuizCard)
- Kolom Kunci    :
  * id (PK)
  * correctCategory (FK -> hardware_categories.id)
- Kolom Penting  : [name, icon, hint, explanation]
- Relasi         :
  * quiz_items --(many-to-one)--> hardware_categories via correctCategory
  * quiz_items --(1-to-1)--> hardware_items via id
